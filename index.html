A self-study vocabulary reference organized by topic. Each topic is a single page with word, part of speech, pronunciation, translation, and an example sentence. Search instantly within any topic.

About this reference

  • Made for studying. Search any topic's word list instantly — no page reload.
  • Grouped by topic. Topics are numbered in the order they're added, starting with 0001.
  • Oxford only. Dictionary look-ups link to Oxford Learner's Dictionaries. Example sentences can be switched between CEFR levels A1–C2, and each word can be marked Memorized, Weak or Need to Learn.
  • Works offline. Every page is self-contained and prints cleanly to PDF (Ctrl/Cmd + P).
